# Bete1geuse - Experimentální Repozitář

Tento repozitář slouží k experimentování s různými programovacími jazyky a technologiemi.

## Struktura

Repozitář je organizován podle programovacích jazyků:

- **Python/** - Experimenty s Pythonem
- **CSharp/** - Experimenty s C#
- **JavaScript/** - Experimenty s JavaScriptem/Node.js
- **Java/** - Experimenty s Javou
- **Go/** - Experimenty s Go
- **Rust/** - Experimenty s Rustem

## Účel

Tento prostor je určen pro:
- Zkoušení nových technologií
- Prototypování nápadů
- Učení a experimentování
- Testování různých přístupů a řešení

Každý adresář obsahuje samostatné experimenty a projekty.
